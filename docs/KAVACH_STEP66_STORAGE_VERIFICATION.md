## 2. Storage RLS Ownership & Anti-Tamper Verification

The policies defined on `storage.objects` in `supabase/migrations/008_kavach_campus_schema_and_rls_alignment_safe.sql` were inspected:

### 2.1 ID Card Upload & Read Isolation:
```sql
-- Insert: Students can only upload to their own folder path
CREATE POLICY "Students upload own ID card" ON storage.objects
FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'kavach-id-cards' 
  AND (auth.uid()::text = (storage.foldername(name))[1] OR name LIKE (auth.uid()::text || '%'))
);

-- Select: Only owner and authorized staff can view
CREATE POLICY "Students read own ID card" ON storage.objects
FOR SELECT TO authenticated
USING (
  bucket_id = 'kavach-id-cards' 
  AND (auth.uid()::text = (storage.foldername(name))[1] OR name LIKE (auth.uid()::text || '%') OR public.is_staff())
);
```
- **Finding:** Student A cannot read or write to Student B's ID card folder path.
- **Reviewer Access:** Authorized reviewers access ID cards via short-lived signed URLs (5-minute expiry) generated by `createSignedUrl` in `/api/admin/verifications`.

### 2.2 Incident Evidence Upload & Read Isolation:
```sql
CREATE POLICY "Authenticated users upload evidence" ON storage.objects
FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'kavach-evidence' 
  AND (auth.uid()::text = (storage.foldername(name))[1] OR name LIKE (auth.uid()::text || '%'))
);

CREATE POLICY "Users and staff read evidence" ON storage.objects
FOR SELECT TO authenticated
USING (
  bucket_id = 'kavach-evidence' 
  AND (auth.uid()::text = (storage.foldername(name))[1] OR name LIKE (auth.uid()::text || '%') OR public.is_staff())
);
```
- **Finding:** Evidence cannot be read by unrelated students.
- **Anti-Tamper Guard:** There are **ZERO `UPDATE`** and **ZERO `DELETE`** policies on `storage.objects`. Once uploaded, evidence cannot be altered or removed by clients.
