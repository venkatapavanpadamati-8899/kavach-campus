## 1. Problem Statement

React 19 and Next.js 16 enforce strict DOM nesting and hydration validation. When the application executed in development mode, an error overlay badge ("1 Issue") appeared on `/admin/ai` and other dashboard views due to invalid HTML5 element hierarchy in `src/components/layouts/DashboardLayout.tsx`.

Specifically:
- An anchor tag (`<a>`) generated by Next.js `<Link>` was wrapping an interactive `<button>` element.
- This violated HTML5 specification: *Interactive content cannot be descendants of the `<a>` element*.
- In React 19, this triggers the `validateDOMNesting` console warning and causes Turbopack to inject a dev error overlay.

## 2. Before & After Code Comparison

### Before (Violation):
```tsx
{/* src/components/layouts/DashboardLayout.tsx - Lines 590-600 */}
<Link href={`${basePath}/incidents`} className="relative">
  <button
    className="p-2 text-slate-400 hover:text-slate-600 dark:hover:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-800 rounded-lg transition-colors relative"
    title="View Incident Alerts"
  >
    <Bell size={17} />
    {incidentCount > 0 && (
      <span className="absolute top-1.5 right-1.5 w-2 h-2 bg-rose-500 rounded-full animate-pulse" />
    )}
  </button>
</Link>
```

### After (Compliant):
```tsx
{/* src/components/layouts/DashboardLayout.tsx - Lines 590-600 */}
<Link
  href={`${basePath}/incidents`}
  className="p-2 text-slate-400 hover:text-slate-600 dark:hover:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-800 rounded-lg transition-colors relative inline-flex items-center justify-center"
  title="View Incident Alerts"
  aria-label="View Incident Alerts"
>
  <Bell size={17} />
  {incidentCount > 0 && (
    <span className="absolute top-1.5 right-1.5 w-2 h-2 bg-rose-500 rounded-full animate-pulse" />
  )}
</Link>
```

## 3. Structural & Accessibility Enhancements

1. **Elimination of Nested Interactive Elements**: The `<button>` tag was removed, allowing the `<a>` tag generated by Next.js `<Link>` to act as the sole interactive element for the notification bell.
2. **Added `aria-label`**: Added `aria-label="View Incident Alerts"` to ensure screen readers provide clear navigational intent.
3. **Flex Centering**: Applied `inline-flex items-center justify-center` directly to the `<Link>` container to preserve exact pixel-perfect icon alignment across all device displays.
4. **Preserved Visual Feedback**: The pulsing notification badge (`animate-pulse`) remains positioned identically (`absolute top-1.5 right-1.5`).
